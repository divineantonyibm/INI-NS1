Section 01

What is IBM NS1 Connect?

IBM® NS1 Connect® is an enterprise-grade, authoritative DNS and intelligent traffic steering platform. Acquired by IBM in 2022 and re-launched as IBM NS1 Connect in October 2023, it transforms the traditionally static Domain Name System (DNS) into a dynamic, real-time decision layer — routing users to the fastest, most available, most cost-effective application endpoint at the moment of each query.

Built on a global anycast network spanning 26 Points of Presence (PoPs) across 6 continents, NS1 Connect offers a 100% uptime SLA for DNS resolution and defends against volumetric DDoS attacks. Its API-first architecture integrates natively with Terraform, Ansible, CI/CD pipelines, and DevOps toolchains.

ℹ

Plain language definition: Think of DNS as the internet's phone book — when you type "myapp.com", DNS tells your browser which server's IP address to connect to. NS1 Connect is a smart, programmable version of that phone book that can pick the best server in real time based on speed, health, location, and your business rules — not just a static list.

Pain Points Addressed

The problems NS1 Connect was built to solve

Traditional DNS is static — records point to IP addresses that don't change unless someone manually updates them. As applications became globally distributed, multi-cloud, and latency-sensitive, that model broke down.

❌ Before NS1 Connect

Static DNS records mean when a server goes down, users get errors until an engineer manually updates the record — potentially hours of downtime.

✅ With NS1 Connect

Health-check monitors detect the outage in seconds. Filter Chains automatically remove the failing endpoint and route traffic to healthy alternatives — zero manual intervention.

❌ Before NS1 Connect

A user in Tokyo gets routed to a US-East server because the CDN contract was set up that way — leading to 400ms+ latency and poor experience.

✅ With NS1 Connect

Pulsar RUM data measures real latency from that Tokyo user's browser in real time and routes them to the Asia-Pacific CDN with the lowest current latency.

❌ Before NS1 Connect

DNS changes require opening tickets, logging into a portal, and waiting for propagation. Every deployment is a manual, error-prone process.

✅ With NS1 Connect

API-first design means DNS updates happen in CI/CD pipelines via Terraform or Ansible. Deployments are automated, repeatable, and auditable.

❌ Before NS1 Connect

A volumetric DDoS attack floods DNS servers, causing all users to lose connectivity — even those trying to reach unaffected services.

✅ With NS1 Connect

The global anycast network absorbs attack traffic across 26 PoPs. Attack volume is spread geographically; legitimate traffic continues uninterrupted.

Section 02

Capabilities of NS1 Connect

NS1 Connect bundles a portfolio of DNS and traffic steering technologies. Below each capability is described both technically and in plain language, with a real-world example.

01

Managed Authoritative DNS

Global Anycast · DNSSEC · 26 PoPs

Creates and publishes DNS zones and records across a globally distributed anycast network. Every record change propagates in under 20 seconds. Supports all standard record types (A, AAAA, CNAME, MX, TXT, SRV, NS, CAA) plus NS1's intelligent answer types.

Plain language: The foundation — your domain's "address book" stored on 26 servers worldwide so lookups are always fast and resilient, no matter where your users are.
02

Filter Chain (Traffic Steering Engine)

Programmable routing pipeline · 15+ filter types

A Filter Chain is a programmable sequence of routing logic applied to every DNS query. Filters include: Up/Down (health), Priority, Weighted Shuffle, Geographic, ASN, Latency, Load, Subnet, and Pulsar performance/availability filters. Filters chain together, passing answers top-to-bottom, eliminating or reordering endpoints based on each filter's rules.

Plain language: Imagine a bouncer who, every time someone calls your website, runs through a checklist: "Is Server A alive? Is it faster than B? Is this user closer to Europe? Send them to the best one." That checklist is the Filter Chain.
03

Pulsar — RUM Traffic Steering

Real User Monitoring · JavaScript beacons · gRPC

Pulsar collects real-time performance and availability measurements from active users' browsers (via a lightweight JS tag or gRPC/HTTP integration). This data is aggregated and fed into Filter Chains so every DNS response reflects the actual current performance of CDNs and cloud regions — not synthetic probes. Community dataset covers 20+ public CDNs and major cloud regions.

Plain language: Instead of guessing which CDN is fastest, NS1 measures it from real browsers in real time. A user in São Paulo gets routed to the CDN that's currently fastest for people in São Paulo — automatically.
04

Health Monitoring & Automated Failover

HTTP · HTTPS · TCP · ICMP · 3rd-party integrations

Continuously probes endpoints (web servers, load balancers, cloud APIs) using configurable health checks. When an endpoint goes down, the monitor updates the record's metadata and Filter Chain logic auto-removes the failing endpoint from DNS responses within seconds. Integrates with Datadog, Catchpoint, ThousandEyes, AppDynamics, and Amazon CloudWatch.

Plain language: NS1 constantly asks "are you OK?" to all your servers. The moment one says "no", it's removed from the list until it recovers — users never see it.
05

Global Server Load Balancing (GSLB)

Geo-routing · Latency-based · Weighted distribution

Distributes user traffic across multiple geographic regions, data centres, or cloud providers based on cost, location, priority, and real-time performance. GSLB uses Filter Chains to combine geographic, latency, and health signals into intelligent multi-region routing policies.

Plain language: You run three data centres — US East, EU West, and Asia Pacific. GSLB automatically sends each user to the nearest healthy one, and if one region goes down, shifts load to the others without any manual steps.
06

DNS Insights & Observability

Real-time analytics · Traffic maps · Anomaly detection

Provides full visibility into DNS query traffic, routing decisions, and endpoint behaviour. Includes customizable dashboards, traffic distribution maps, query volume reports, and anomaly detection policies. DNS Insights (add-on) identifies misconfigurations before they impact users.

Plain language: A live control room for your DNS — see exactly where queries are coming from, how traffic is being distributed, and get alerts if something looks wrong before your users notice.
07

Cloud Sync (Multi-Provider DNS)

Amazon Route 53 · Bi-directional sync · No XFR required

Automatically synchronises authoritative DNS data between NS1 Connect and Amazon Route 53. Teams can run NS1 as primary and Route 53 as secondary (or vice-versa) without changing primary DNS workflows. Eliminates manual duplication and keeps multi-provider configurations always in sync.

Plain language: If you already use AWS Route 53, Cloud Sync lets you add NS1 as a backup DNS without any extra manual work — changes in one automatically appear in the other.
08

Dedicated DNS

Single-tenant · Physically isolated · Private network

A private, physically and logically isolated DNS network separate from the shared NS1 Connect infrastructure. Eliminates noisy-neighbour risk and provides maximum resilience for organisations with strict security or compliance requirements. Can be combined with Managed DNS for dual-layer redundancy.

Plain language: Your own private DNS highway — no one else's traffic ever shares your infrastructure, giving you maximum security and consistency.
09

API-First Automation & Integrations

REST API · Terraform · Ansible · CI/CD · SDKs

Every NS1 Connect feature is available via a fully documented REST API. Official Terraform provider, Ansible modules, and SDKs (Go, Python, Java) allow teams to manage DNS as code in any DevOps workflow. Zone creation, record updates, and policy changes can all be automated.

Plain language: DNS updates happen automatically as part of your software deployments — no one has to log in and change anything manually. It's DNS treated like any other piece of infrastructure code.
10

URL Redirects & SSL Management

HTTP/HTTPS · Let's Encrypt auto-SSL · Vanity URLs

Manages HTTP and HTTPS URL redirects without additional infrastructure. Supports vanity URLs, domain forwarding, and application migration redirects. Automatically provisions and renews SSL/TLS certificates via Let's Encrypt for HTTPS redirects.

Plain language: Set up "old-brand.com → new-brand.com" redirects — including HTTPS with valid SSL certificates — all from the same NS1 dashboard, no extra servers needed.
11

DDoS Protection

Anycast diffusion · Multi-layer filtering · Scrubbing

The global anycast network inherently absorbs volumetric DDoS attacks by distributing traffic across 26 PoPs. Attack packets are spread and absorbed geographically rather than concentrating at a single target. Intelligent filtering distinguishes legitimate queries from attack traffic.

Plain language: Like flood-proofing a city with 26 drainage channels instead of one — an attack flood gets spread across all channels so no single point is overwhelmed.
12

Managed DNS for China

China CDN · Great Firewall optimisation · Up to 3× faster

Optimised DNS delivery for users in mainland China, accounting for the unique challenges of the Chinese internet ecosystem. Delivers up to 3× faster DNS performance compared to standard global DNS for Chinese users.

Plain language: China's internet has special rules and bottlenecks. NS1's China option routes traffic through a network optimised for those conditions so your app loads fast for users in Shanghai or Beijing.

Section 04

Real-World Use Cases & Problems Solved

NS1 Connect is deployed across industries wherever applications must be fast, highly available, and globally distributed. Here are eight concrete, real-world scenarios where NS1 Connect makes the critical difference.

🎬 Streaming & Media

Live Event: Zero Buffering for Millions

A major streaming platform broadcasts a championship final to 30 million concurrent viewers globally. Traffic spikes 10× in seconds. One CDN in Europe degrades due to network congestion. NS1 Pulsar detects the degradation from real browser measurements and automatically shifts European traffic to a healthy alternate CDN — all within one DNS TTL cycle.

Outcome: Viewers experience seamless playback. The platform avoids a PR disaster and protects subscription revenue. Used by customers like Disney Streaming and BBC.

🛍️ E-Commerce & Retail

Black Friday: Site Stays Up During Peak

An online retailer runs three data centres across US East, EU, and APAC. On Black Friday, US East becomes overloaded. NS1's GSLB with weighted Filter Chains detects elevated latency, shifts 40% of US traffic to EU West, and routes APAC users to their nearest healthy endpoint — all automatically while the engineering team focuses on scaling.

Outcome: Zero downtime during peak. Estimated 30–35% reduction in manual ops time. Customers like Wayfair and eBay rely on NS1 for peak traffic resilience.

💰 Financial Services

Geo-Compliant Routing for Regulatory Requirements

A global bank must ensure European customers' data never leaves the EU and Asian customers are served from APAC data centres to comply with local data residency laws. NS1's geographic filter chains route users based on their IP's country of origin, ensuring compliance automatically while still providing low-latency access.

Outcome: Automated regulatory compliance for data residency. No manual routing rules to maintain per-country. Used by Deloitte and financial institutions globally.

🏥 Healthcare

Always-Available Patient Portal During Outages

A hospital network's primary data centre goes offline during a maintenance window that overruns. The patient portal, appointment system, and telemedicine platform must remain accessible. NS1's automatic failover, configured in advance, detects the primary DC failure within seconds and routes all traffic to the disaster-recovery site — without a single phone call to IT.

Outcome: Patient-critical services remain online. SLA met. Application uptime improved by 40–45% after NS1 deployment.

🎮 Gaming

Low-Latency Matchmaking for Global Players

A multiplayer game launches simultaneously in 50 countries. Players need sub-50ms connections to game servers or gameplay feels laggy. NS1 Pulsar routes each player to the game server region with the lowest real-time latency for their specific location and ISP — not just the geographically nearest server, which may be congested.

Outcome: Reduced player lag, lower drop rates, and improved engagement during launch day peaks. Gaming companies see meaningful improvement in player retention.

☁️ SaaS & Cloud Platforms

Multi-Cloud DNS Without Lock-In

A SaaS company runs workloads across AWS, Azure, and GCP. They use AWS Route 53 as primary DNS but want NS1's intelligent traffic steering and a backup DNS provider. NS1 Cloud Sync keeps both in sync automatically. If Route 53 has an outage, NS1 Dedicated DNS takes over immediately with zero manual intervention.

Outcome: True multi-provider DNS resilience. No vendor lock-in. Teams like Salesforce and Workday use NS1 for enterprise-grade DNS reliability.

📰 News & Publishing

Breaking News Traffic Surge Management

A major news site experiences unpredictable 50× traffic spikes when a major story breaks. Their origin servers can't handle the load alone. NS1 routes the majority of traffic to CDN edge caches based on current CDN performance data, falls back to origin only for dynamic content, and shifts CDN providers if one degrades — all without human action.

Outcome: Articles load fast during viral moments. No "site under load" pages. Bloomberg, BBC, CNBC, and Gannett use NS1 for just this scenario.

🔐 Cybersecurity & Network Ops

Surviving a DDoS Attack on DNS Infrastructure

An enterprise's DNS infrastructure is targeted by a 500 Gbps volumetric DDoS attack. Traditional single-provider DNS would be overwhelmed. NS1's global anycast network distributes the attack traffic across 26 PoPs, absorbing it geographically. The 100% uptime SLA holds; legitimate user queries continue without interruption throughout the attack.

Outcome: Zero DNS downtime during an active DDoS attack. Business continues normally. Avast (cybersecurity firm) relies on NS1 for this exact scenario.
